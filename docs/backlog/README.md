# Backlog records

GitHub Issues is authoritative for upcoming requests, specifications, and status. [BACKLOG.md](BACKLOG.md) is a small imported-scope index only and retains its parser-compatible six-column format. [SHIPPED.md](SHIPPED.md) records dated completed intent and issue/PR links separately.

The original planning map and scope notes are preserved in the [history snapshot](../history/backlog/2026-10-06-BACKLOG.md). Capture new requests as issues without copying their full bodies into the backlog. When an imported scope ships, remove its table row and update SHIPPED in the same implementation change. Detailed notes remain linked from issue history; closed issues retain their historical specifications.

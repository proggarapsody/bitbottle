# Project agent resources

Engineering skills live in `skills/`; project knowledge lives in the existing
repository docs. Start with [the knowledge map](../docs/agents/README.md).
The root [AGENTS.md](../AGENTS.md) remains the repository instruction entry point.

`history/` is ignored local evidence, including completed TDD sessions, review
notes, original design notes, and snapshots of legacy runtime ledgers. It is not
an instruction source. See `history/legacy-workflow/migration-manifest.json` for
original paths and SHA-256 hashes. No credentials or user settings were copied.

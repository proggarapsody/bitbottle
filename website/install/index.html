Installation

Get bitbottle on your machine.

Choose npm for the packaged CLI, or install the Go command directly.

Install with npm

Requires Node.js and npm. The package installs the command and can register its bundled agent skill with detected runtimes. 

npm install -g @proggarapsody/bitbottle

Skip skill registration with BITBOTTLE_SKIP_SKILL_INSTALL=1.

Install with Go

go install github.com/proggarapsody/bitbottle/cmd/bitbottle@latest

Other packages

Homebrew, binary, Debian, RPM, and Docker packages are listed on the latest release.

Find a command

bitbottle --help
bitbottle pr --help
Backend capabilities vary. Some operations are available only on Cloud or only on Server/Data Center. Check the command support matrix.

Frequently asked questions

Is bitbottle an official Atlassian product?

No. It is an independent open-source project and is not affiliated with or endorsed by Atlassian.

Is it the Rust Bitbucket CLI?

This is the Go CLI published as @proggarapsody/bitbottle. A separate Rust project uses a similar name; this site documents github.com/proggarapsody/bitbottle.

AI clients and MCP

Give compatible AI tools a path to Bitbucket.

Bitbottle includes a local Model Context Protocol server and a bundled agent skill that describes how to use its CLI.

Run the MCP server

Start the stdio MCP server from an environment where bitbottle is installed: 

bitbottle mcp serve

Configure a compatible MCP client to launch that command as a local stdio server. Available operations depend on the selected host.

Install the bundled skill

npm install -g @proggarapsody/bitbottle

Skip automatic registration with BITBOTTLE_SKIP_SKILL_INSTALL=1. Other installation methods can use: 

bitbottle skill install
bitbottle skill path
bitbottle skill remove

Keep the agent in scope

The skill gives an agent command context. Host configuration provides access. Review write operations before relying on an automated workflow. Cloud and Server/Data Center expose different feature sets.

See the source skill documentation and sample pull request workflows.

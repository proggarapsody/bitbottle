Pull request workflow

Review and move pull requests from the terminal.

Bitbottle brings common Bitbucket pull request operations to a consistent CLI across Cloud and Server or Data Center, with host-specific capabilities called out.

Find and inspect work

bitbottle pr list
bitbottle pr view 42
bitbottle pr diff 42
bitbottle pr checkout 42

Inside a repository with a Bitbucket remote, bitbottle can resolve repository context. Use -R HOST/PROJECT/REPO to select one explicitly.

Create and review

bitbottle pr create --title "feat: add retry logic" --base main
bitbottle pr request-review 42 --reviewer alice
bitbottle pr approve 42

Merge with intent

bitbottle pr merge 42 --squash --delete-branch

Merge options depend on host and repository configuration. Bitbottle returns typed errors for conditions such as a conflicting or behind pull request.

Check host support. Reopening a pull request is Server/Data Center only. Check the support matrix for other host-specific commands.

Use structured output

bitbottle pr list --json number,title,state
bitbottle pr list --json number,title,state --jq '.[] | select(.state == "OPEN")'

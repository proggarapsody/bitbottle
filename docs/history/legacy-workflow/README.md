# Retired custom workflow

These are byte-preserved snapshots of the former automatic iteration procedure,
Claude command adapters, and merge checklist. They are historical source
material, not discoverable commands or current repository instructions.
Relative links and command paths inside these snapshots retain their original
context; use the migration manifest to locate moved files.

The current workflow is described by [the knowledge map](../../agents/README.md)
and [the merge checklist](../../workflows/pre-merge-check.md). Existing shell
utilities remain under `auto-iter/scripts/` and are still covered by CI.

To study a previous iteration, start with a dated report in
[iterations/](../iterations/) and consult the raw local ledgers when needed.

## Recurring patterns

### Auto-merge race (5 of 10 cycles, regression from 2 of 10)

CI (~2min) completes and fires auto-merge before DJ (~3–5min) returns verdict.
The ordering mitigation from prior streams (run DJ concurrently with CI) is
insufficient — it only helps when DJ finishes before CI, which is not guaranteed.

**Pattern in every affected cycle:**
1. `git push` → arm auto-merge → await CI → CI green → PR merges
2. DJ returns BLOCKER *after* merge → follow-up fix PR required

**Cost per occurrence:** ~1 extra PR cycle, ~8–10 min wall, 1 extra release bump.
**Total cost this stream:** ~50 min + 5 extra PRs.

### Integration test omission (cycles 185, 187)

Two consecutive cycles (REPO-SYNC, COMMIT-SEARCH) had missing integration tests.
ARCHITECTURE.md §"Test tiers" requires tier-2 integration tests for every new
command. TDD subagent prompt must explicitly require `*_integration_test.go`.

## Recommended fixes (ranked ROI)

### Fix 1 — DJ-then-arm gate (HIGH, ~20 LOC, CRITICAL)

**Problem:** Auto-merge fires when CI completes (~2min), before DJ returns
(~3–5min). Five BLOCKERs escaped post-merge.

**Fix:** Sequence must be:
```
push → await DJ VERDICT → if BLOCKER: push fix → re-run
               ↓ SHIP
arm auto-merge → await CI → merge
```

This is the inverse of the current sequence. DJ must block auto-merge arming.

**Files:** `docs/workflows/iteration-cycle/README.md` §3.6,
`.claude/commands/auto-iter.md` (§ In-cycle parallel block).

### Fix 2 — TDD subagent prompt: require integration test (MEDIUM, ~2 lines)

**Problem:** Cycles 185, 187 both omitted `*_integration_test.go`.

**Fix:** Add to the mandatory TDD subagent prompt checklist:
> "Create `<command>_integration_test.go` using httptest — see `pkg/cmd/repo/sync/sync_integration_test.go` for the canonical pattern. Tier-2 integration test is required for every new user-visible command."

**File:** `.claude/commands/auto-iter.md` (TDD subagent prompt requirements section).

### Fix 3 — Token data for all cycle types (LOW, ~5 lines)

**Problem:** Cycles 179, 182 (chore/brainstorm) log `"tokens": 0` even though
work was done.

**Fix:** Emit actual subagent tokens to `log-cycle.sh` for brainstorm cycles via
`--tokens` flag (captured from metric.sh step2_brainstorm line).
